Panduan

Layar mati & keamanan data

Aman saat layar mati: catatan lapangan, tanda dikunjungi, koreksi posisi pin, titik tambahan, dan titik jejak yang sudah terekam tersimpan otomatis di browser.
Tidak terekam saat layar mati: posisi dan jejak GPS terhenti ketika layar terkunci atau browser berada di latar belakang, sehingga jejak ada celah. Saat halaman dibuka lagi, posisi menyala kembali otomatis. Data yang sudah tersimpan tidak hilang.
Agar jejak utuh: biarkan browser di depan selama merekam. Layar ditahan menyala otomatis saat Rekam jejak aktif.
Data bisa hilang jika: data browser/situs dihapus, memakai mode samaran (incognito), pindah browser atau HP, atau membuka file dari WhatsApp (bukan link https). Ekspor GeoJSON dan GPX saat istirahat siang dan di akhir hari.

Catatan data

Dasar penentuan posisi tiap titik S32-S41 tercantum di popup masing-masing. Titik S32-S41 (persampahan, penyamakan, Cimanuk) ditambahkan dari catatan; koordinatnya perkiraan. Titik S42-S51 (Flood West Java) memakai koordinat dari KMZ (tanpa data spasial), geser/koreksi saat di lapangan. Status TPA Pasir Bajing (kebakaran, penolakan warga) berasal dari pemberitaan Okt 2026.
Verifikasi: banjir bandang 2016/2022 (sempadan, tanggul, relokasi, kolam retensi), kekumuhan & sanitasi area penyamakan, status IPAL komunal Sukaregang (5-6 unit, rusak) dan rencana IPAL terpusat + IPLT utara. Cantumkan foto sungai Cimanuk.
Arteri primer berasal dari 06_TRANSPORTASI_LN.shp; kolektor dari layer RTRW. Beberapa ruas berbeda kelas antar sumber (mis. Jl. Cimanuk, Jl. Suherman, Jl. Raya Samarang), perlu konfirmasi ke Bina Marga.
Hotspot adalah lingkaran indikatif (r 1,5 km) hasil digitasi kasar dari slide, bukan poligon MapBiomas.
Exit tol hanya satu titik tanpa atribut. Titik "Persilangan tol-jalan" adalah hasil geometri, bukan lokasi exit resmi.
Cagar budaya: hanya Makam Keramat Godog sebagai kandidat; tidak ada layer cagar budaya.
Peta dasar OpenStreetMap butuh internet; tanpa itu layer data tetap tampil. Pelacak GPS butuh izin lokasi; di HP lebih andal bila file dibuka lewat https (mis. di-host), karena beberapa browser membatasi GPS pada file lokal.
